# 大小球变盘扫描器 - 会员版（程序猿：小虾米 · 数据源 titan007）

## 它做什么

轮询球探网（titan007）当天比赛的大小球（进球数）盘口，比较 **初盘** 与 **即时盘**，
当盘口线差达到设定阈值（默认 0.25）时，把比赛列出来并提醒一次。数据全部来自
titan007 的公开页面，不需要卡密、不需要登录。

## 文件

| 文件 | 作用 |
|:---|:---|
| `scan_gui.py` | 窗口版（推荐）：表格显示、报警、导出 CSV |
| `scan.py` | 命令行版：适合挂后台/计划任务 |
| `scanner_core.py` | 扫描核心逻辑 |
| `titan_common.py` | titan007 公共页面抓取与解析 |
| `scan_gui.bat` | 双击启动窗口版 |

## 运行

```bat
scan_gui.bat
```

或命令行：

```bat
python scan.py --threshold 0.25 --interval 60 --cid 1
python scan.py --once --limit 50
```

参数：

| 参数 | 默认 | 说明 |
|:---|:---:|:---|
| `--threshold` | 0.25 | 初盘→即时盘盘差阈值 |
| `--cid` | 47 | 指数公司 ID（47=平博，1=澳门，8=36，12=易胜博…） |
| `--interval` | 60 | 每轮间隔秒数 |
| `--workers` | 4 | 并发数（超过 4-6 可能被站点限流） |
| `--limit` | 0 | 只扫前 N 场 |
| `--csv` | alerts.csv | 报警 CSV |

## 数据说明

- 初盘/即时盘取“变化表”最后一行/第一行：最后一行=最早记录（开盘），第一行=最新。
- 部分比赛某家公司不开大小球盘，会显示“该公司未开”，属正常。
- 页面按 GB18030/UTF-8 自适应解码；中文乱码通常是临时网络问题，重试即可。

仅供学习参考，不构成任何投注建议。
